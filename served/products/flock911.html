FAQ

What is Flock911, and how does it help officers in the field?

Flock911 streams live 911 calls and transcripts to patrol officers, RTCC operators, and Drone as First Responder pilots. This gives them immediate insight into the emergency as it’s happening, enabling faster, more informed response.

How does call filtering work?

Flock911 filters calls for patrol using vehicle location and/or zone geofencing. RTCC users can use zone geofencing to focus on their desired areas. These tools are used to ensure that no alerts are missed and efforts are focused where they’re needed, without distraction.

Do officers need to install a new app to use Flock911?

No. Flock911 is delivered via the existing Flock Safety Platform alerts interface for patrol and FlockOS map for RTCC users. There’s no additional software to install or learn, so adoption is fast and seamless.

Can 911 audio be reviewed after the incident?

Yes, officers can replay 911 calls and reference full transcripts for incident documentation or follow-up investigations.
