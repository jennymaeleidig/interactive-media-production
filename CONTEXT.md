# CONTEXT.md

Glossary for this repo. Terms are added as they resolve in conversation; no implementation detail lives here.

## Terms

- **The piece** — the chat and the page that carries it: one conversation, one canvas with nothing else on it. _Avoid_: the site, the demo, the app.
- **Chat surface** — the one full-viewport column the conversation plays in: the floating capsule header (wordmark and the `?` info affordance) and the chip-row composer tray with its inert send glyph. No launcher, no panel, no text input. Its look is the vendored React shell's, styled from the lock ADR's tokens. _Avoid_: bubble, chat window, chatbot UI, launcher, widget.
- **Chat runtime** — the one file carrying the dialogue engine with the compiled program inlined, `/chat/runtime.js`. The React shell is part of the page's own bundle and reaches the engine only through the declared chat interface. They cannot ship out of step because they are one file. _Avoid_: bundle, main script.
- **Dialogue program** — the Yarn sources `dialogue/core.yarn`, `dialogue/products.yarn`, `dialogue/trust.yarn`, compiled together into `scripts/chat-program.json` at build time, because a browser cannot compile Yarn. Node titles are one namespace across the three files.
- **Command declaration** — `dialogue/definitions.ysls.json`, named by the project file `dialogue/flock.yarnproject`: the piece's one custom command, `<<block "id" [new|join]>>`, with its parameters and arity — `join` is optional and the default. The editor reads it to stop calling `block` unknown, and the build runs the same check on the same declaration, so a command typo fails here and not only there. _Avoid_: command list, command registry, ysls file.
- **Block** — one typed piece of a reply: `text`, `image`, `frame`, `link`, `me`, or a designed fallback for an unknown type. A reply is a sequence of blocks; consecutive same-speaker blocks share a bubble unless the author marks one to start a new one. A block named in the dialogue program is declared in the block inventory. _Avoid_: attachment, card — a grouped run is a Message.
- **Message** — the blocks one speaker sends between bubble cuts: consecutive same-speaker blocks sharing one bubble. A reply is a sequence of messages; a message is a sequence of blocks. The transcript groups the block log into messages, and a message's identity is the log position of its first block (see Message identity). A message that landed in a live turn types itself out; one restored from the log renders whole (see Fresh message). _Avoid_: bubble group, card, segment.
- **Block inventory** — the hand-reviewed declaration of every block the piece can render, every remote source it may reach, and each renderable type's contract terms — the typing-beat weight its content holds and the frugality rules its render must follow — `lib/chat-blocks.mjs`. The no-ask rule's allowlist is the set of its sources. _Avoid_: block table, registry, whitelist.
- **Message identity** — the id of one message, derived from the position in the conversation log of the run's first block. The log is append-only and persisted, so identity survives turns, a reload-resume, and any rework of grouping or payloads: the transcript grows, it does not reshuffle. _Avoid_: render-order id, positional id.
- **Fresh message** — a message that landed in a live, held turn, the reply the viewer is watching arrive. Only a fresh message types itself out; a restored transcript (the opening turn, a resume, a remount) renders whole, so the reveal never replays. The viewer's own line is never fresh-composed: it lands as log, whole. _Avoid_: animated message, new message.
- **Voice** — the animalese letter speech under a fresh message's reveal: one synthesized sound per character, pitched, paced, and levelled from the viewer's settings (`lib/settings`, defaults in `lib/pacing`). The typing is the clock: the voice starts and stops with it, so a voice slower than the reveal does not finish every letter and the next message is never held for it (`lib/turn-plan.ts`, `lib/voice.ts`). Only a fresh message speaks; the viewer's line and a restored transcript stay silent. One engine is shared by the whole conversation, not one per bubble. _Avoid_: speech synthesis, TTS, sound effect, audio playback.
- **Turn contract** — the request and response shape declared in `lib/chat-turn.mjs`: open (resume the live session or begin one) and option (select a pending choice) in; the whole block sequence, the choice set, and the session's report out. It is in-process, not server-shaped: there is no conversation id on it and no separate replay. The chat surface speaks it; the engine answers it.
- **Session** — `localStorage['flock-chat-state']`, the engine's snapshot of the one conversation: its block log, variables, current node, and completion. A reload resumes rather than restarts. The engine owns it; the chat surface keeps no copy. _Avoid_: history, transcript, thread.
- **Copy provenance** — every scripted line is marked OBSERVED (verbatim from the one observed session), ADAPTED (an OBSERVED line whose speaker name changed), or AUTHORED (written for the piece, each claim carrying the Flock page it comes from). An AUTHORED line never says something no source says. The tests lock all three, so a copy change fails rather than drifts. _Avoid_: pinned copy, canned answers, canned responses.
- **Cam** — the piece's one character and the speaker of every scripted line. The name is the piece's own, and the one deliberate deviation from the observed surface: the real widget introduced itself as "Flock". Every line is written `Cam: …`, and that leading marker is the speaker, never rendered. _Avoid_: bot, assistant persona, avatar name.
- **Hub** — the return gate every flow lands on: one line ("Is there anything else I can help you with today?") and one chip set (Products & offerings, Get a Demo, Privacy & safety, Support, That's all for now), identical on every return and never a second greeting. First contact offers the general beat instead of the exit. _Avoid_: menu, main menu, root, home.
- **Flow** — one branch reached from first contact or the hub: the general answer, Products & offerings, Get a Demo, Privacy & safety, and Support. A flow's spokes end at the hub; deeper branching stays inside a flow. _Avoid_: topic, section, journey.
- **Bubble cut** — the authored boundary that ends a reply's bubble mid-run: `#newmessage` at the end of a line, the text counterpart of `<<block "id" new>>`. Untagged consecutive Cam lines share one bubble. _Avoid_: message break, line break, newline.
- **Email gate** — the demo ask that stops: the piece collects no address and books no meeting, and "Maybe later" is the only chip on it. It returns to the hub rather than re-greeting, so the conversation never dead-ends. _Avoid_: lead capture, contact form.
- **Restart** — the way back in once a conversation has run out: the engine's `reset` drops the session and lands the greeting again, and the dialogue hook reports a completed conversation so a control can read it. A finished conversation resumes finished, so with no restart control authored yet the sign-off is currently the end of the line. _Avoid_: start over (the dev-only control's label), new session, replay.
- **Inert composer** — the composer tray is chrome: the send glyph is present and does nothing, and only the chips advance the conversation. _Avoid_: disabled input, stub, placeholder form.
- **Assistant mark** — the Flock mark on its disc beside the first bubble of an assistant run, the reference widget's own placement; the viewer's turn carries none. Decorative — the bubble is the message — and inline SVG sharing one geometry with the wordmark. _Avoid_: avatar, icon, badge, profile picture.
- **Day divider** — the stamp above the first bubble ("Today, 12:15 am"), in the reference widget's own 12-hour format rather than the viewer's locale. It is read from the viewer's clock when the piece opens and never stored or sent. _Avoid_: timestamp, date separator, date header.
- **Published path** — a URL the host serves from a maintained file, declared in `scripts/chat-assets.mjs`: `/chat/runtime.js`. There is one declaration because the route, the artifact check and the seam all read it. _Avoid_: static asset, mirror, bundle name.
- **No-ask rule** — the piece asks its viewer for nothing and keeps nothing about them: no form, no capture, no analytics, no viewer identifier, and no request whose target or payload is derived from viewer input (`CODING_STANDARDS.md`). The page reaches the network only at authored block URLs.
- **Seam** — a place where a test drives the piece from outside: the engine seam, the interface-shape seam, and the artifact seam. _Avoid_: unit boundary, integration layer, mock.
- **Disclosure** — the plain-voice, out-of-character notice behind the `?` in the viewport's top-right corner, owned by the host page: two pages under one roof, **Settings** first and default, **About** second. The one place the piece drops the mask; verisimilitude is preserved by placement (a popover, never a banner), not by wording. _Avoid_: legal notice, banner, cookie-style modal.
- **Tooltip** — the disclosure's drawn form: the bubble that lands from below the `?`, in Denton, over a blurred laminate chip (`docs/brand.md`). The word names the surface, not a second component — the behaviour stays the `Disclosure` term's. _Avoid_: hint, hover card, help bubble.
- **Share kit** — the maintained document `docs/share.md` carrying the honest path out for a viewer stopped at a browser interstitial before the piece loads: what the piece is, the way through the warning, the false-positive report link, and the URL in the clear. Prose, not runtime — nothing serves it at a published path, because anything on the piece's own domain sits behind the interstitial; it reaches viewers only as pasted text. It also declares the one canonical honest string, which the page's `og:title` / `og:description` / `meta description` carry in trimmed form. _Avoid_: share text, share blurb, share link.
- **Settings** — the `?` popover's first page and the piece's accessibility surface: one slider for every lever a viewer may tune — the voice's volume, pitch, spread, and speed, and the piece's typing, thinking, and pause paces — read from one declaration (`lib/settings`) with the piece's own tuning (`lib/pacing`) as the defaults. Kept in the viewer's browser under its own key (`flock-chat-settings`) and never sent (ADR 0006); **Start over** clears the conversation, not a preference. _Avoid_: preferences panel, options, config.
- **About** — the `?` popover's second page: the plain sentence, the marks' provenance, the pointer to the real Flock, and the privacy policy. _Avoid_: credits, info, more.
- **Freshness gate** — `npm run chat:check`: regenerate the program and the runtime in memory, and fail when the committed files differ.
- **Artifact check** — `npm run check:artifact`: the built export, read back over HTTP. Environmental rather than a suite member, because it needs a build.
